# ChatGPT Obsidian Exporter

**Сохраняйте переписки ChatGPT, код, документы и результаты работы в архиве для Obsidian.**

[English](README.md) · [Русский](README.ru.md) · [Установка](#быстрая-установка) · [Формат архива](docs/export-format.ru.md) · [Участие в разработке](CONTRIBUTING.ru.md)

**Версия:** 0.3.9.2 · **Платформа:** Chrome Manifest V3 · **Статус:** стабильный релиз

ChatGPT Obsidian Exporter — расширение Chrome, которое сохраняет **один открытый разговор ChatGPT** в ZIP. Внутри: читаемая Markdown-переписка, нумерованный протокол со ссылками Obsidian, доступные вложения и изображения, исходный JSON и отчёт о полноте экспорта.

> **Неофициальный проект, не связанный с OpenAI или Obsidian.** Внутренние интерфейсы ChatGPT могут меняться; полного серверного экспорта расширение не гарантирует.

## Зачем это нужно

- **Сохранять результаты:** код, тексты, документы, изображения и схемы вместе с контекстом их создания.
- **Быстро находить решения:** навигационный протокол ведёт к конкретным этапам разговора.
- **Не копировать всё вручную:** экспортировать доступный материал и файлы за один запуск.
- **Видеть ограничения:** отчёт показывает скачанные, пропущенные и недоступные вложения.
- **Сохранять первоисточник:** исходный JSON и DIL-разметку можно изучить или повторно преобразовать в будущем.

## Автоматизация через кнопку на странице (v0.3.9.2)

В правом нижнем углу открытого разговора ChatGPT появляется кнопка **«Экспорт ZIP»**. ИИ-агент может нажимать её непосредственно через DOM, не открывая Popup и не внедряя свой JavaScript. Старый запуск через Popup и его настройки сохранены.

- Кнопка существует только на доменах ChatGPT и отображается только на страницах диалога, включая переходы без перезагрузки.
- Первая галочка в Popup — **«Включить кнопку»**. По умолчанию включена. При снятии галочки кнопка сразу исчезает из открытого ChatGPT (текущий экспорт не прерывается), при установке появляется снова. Выбор сохраняется между перезапусками браузера и действует для всех вкладок. Ручной экспорт через Popup остаётся доступным.
- Разрешение Chrome `storage` необходимо только для локального хранения состояния этой галочки; дополнительных разрешений на сайты не требуется.
- Селектор для агента: `#chatgpt-obsidian-export-zip-button`. Статусы атрибута `data-export-status`: `idle`, `running`, `ready`, `error`.
- Панель `#chatgpt-obsidian-export-panel` показывает ход работы и итоговый статус `data-export-status` (`running`, `ready`, `error`).
- **ready означает, что ZIP сформирован и браузеру отправлен запрос на скачивание**, но не гарантирует, что файл уже записан на диск. Агент должен отдельно проверить загрузки своей среды.
- Фиксированные параметры: все доступные исходящие файлы и изображения, **входящие вложения пользователя**, пауза 1,5 секунды между загрузками, ограничение 100 МБ на файл и ранее существующий суммарный лимит/отчёт об ошибках.

Работа кнопки, скачивание доступных файлов и настройка видимости проверены в Chrome. Установочный ZIP доступен в [GitHub Releases](https://github.com/dmitromelnikoff/chatgpt-obsidian-exporter/releases/tag/v0.3.9.2): распакуйте его в постоянную папку и загрузите её через `chrome://extensions` → «Режим разработчика» → «Загрузить распакованное».

## Быстрая установка

Корень репозитория — **сама папка распакованного расширения**. Для локальной установки не нужны npm и сборка.

1. Скачайте установочный ZIP из [GitHub Releases](https://github.com/dmitromelnikoff/chatgpt-obsidian-exporter/releases/tag/v0.3.9.2) или клонируйте репозиторий и сохраните файлы в постоянной папке.
2. Откройте `chrome://extensions`, включите **Режим разработчика** и нажмите **Загрузить распакованное расширение**. Выберите папку, содержащую `manifest.json`.
3. Откройте нужный чат по адресу `https://chatgpt.com/c/...` и нажмите кнопку **«Экспорт ZIP»** справа внизу или значок расширения для ручной настройки.
4. В режиме Popup при необходимости настройте файлы, изображения и входящие вложения; кнопка на странице использует фиксированные параметры, включая входящие материалы.
5. Дождитесь ZIP; состояние процесса отображается во вкладке ChatGPT.
6. Распакуйте **всю корневую папку экспорта** в Obsidian vault. Откройте `00_Протокол.md`.

Для обновления замените файлы в папке расширения и нажмите **Обновить** на странице расширений. Не устанавливайте параллельно несколько копий без необходимости.

**Публикации в Chrome Web Store пока нет.** Другие Chromium-браузеры не проходили отдельную матрицу совместимости.

## Структура ZIP

```text
Название чата_ГГГГ-ММ-ДД_ЧЧ-ММ-СС/
├── 00_Протокол.md
├── 01_Переписка/
│   ├── Часть-001.md
│   └── Часть-002.md
├── 02_Артефакты/         # Если есть сохранённые файлы
├── 03_Исходники/
│   ├── conversation.json
│   ├── conversation.log
│   ├── artifacts.json
│   ├── steps.json
│   ├── manifest.json
│   └── DIL/              # Для отдельных сложных компонентов
├── 04_Отчёт экспорта.md
└── README.md
```

Временная метка позволяет сохранять несколько экспортов. Чтобы ссылки работали, переносите корневую папку целиком. Подробнее: [Формат экспорта](docs/export-format.ru.md).

## Настройки

- **Вложить доступные файлы** — включено по умолчанию.
- **Вложить доступные изображения** — включено по умолчанию.
- **Скачать входящие вложения** — выключено по умолчанию.
- **Дополнительный LOG рядом с ZIP** — по желанию (внутри ZIP LOG есть всегда).
- **Пауза между скачиваниями** — по умолчанию 1,5 секунды, 0,5–30 секунд или отключение.
- **Максимальный размер файла** — 100 МБ по умолчанию; значение настраивается в окне расширения.

Для временных ошибок предусмотрено не более двух повторов и учёт `Retry-After`. Общий бюджет скачанных вложений — 512 МиБ. Недоступные файлы не выдаются за сохранённые.

## Устройство и разработка

Расширение не требует npm-пакетов и внешних библиотек. Основные модули:

| Файл | Назначение |
| --- | --- |
| `manifest.json`, `popup.html`, `popup.js` | Manifest V3, интерфейс, настройки и инъекция скриптов. |
| `page.js` | Доступ к текущему чату, API ChatGPT, загрузка вложений и сборка. |
| `core.js` | Нормализация сообщений, шаги, реестр артефактов, структура файлов. |
| `renderer.js` | Преобразование Markdown и поддерживаемого DIL, безопасные SVG. |
| `reliability.js` | Повторы, задержки и классификация ошибок. |
| `zip.js` | Локальная сборка ZIP32 без сжатия, CRC32 и UTF-8. |

[Архитектура](docs/architecture.ru.md) · [Разработка и тесты](docs/development.ru.md) · [Устранение проблем](docs/troubleshooting.ru.md)

### Команды проверки

## Безопасность и ограничения

Разрешения браузера: `activeTab`, `scripting` и `storage` (локально сохраняемая настройка видимости кнопки). Расширение читает открытый чат, обращается к API ChatGPT и разрешённым адресам файлов через текущую сессию браузера; ZIP создаётся локально. В проверенной версии нет отдельного сервера разработчика для загрузки ваших данных и нет аналитики. **Не публикуйте ZIP, LOG и необезличенные JSON своих разговоров.**

- Интерфейсы ChatGPT могут измениться.
- Экспорт содержит доступные данные текущей сессии и выбранной ветки, не обязательно все серверные сообщения.
- Intelligent UI сохраняется в виде статического представления; динамическое поведение, недоступные картинки и некоторые источники цитат не восстанавливаются.
- Изображения инструментов могут быть промежуточными или недоступными для скачивания.
- Ограничения сервера и лимиты размеров отражаются в отчёте.
- ZIP использует режим STORE (без сжатия), поэтому может быть большим.

Подробнее: [Безопасность](SECURITY.md) · [Приватность](docs/privacy.ru.md).

### Как агенту интерпретировать полноту экспорта

Число исключённых API-записей само по себе не означает потери сообщений: читаемый протокол намеренно оставляет пользовательские ответы и запросы, а доступные исходные записи хранятся в `03_Исходники/conversation.json`. Поле `excluded_message_reasons` показывает причины исключения.

Для постраничного API значение `pagination_status: "exhausted"` и `pagination_exhausted: true` означает, что экспортёр последовательно получил страницы до явного сообщения API об отсутствии более старых страниц. `metadata_missing` означает отсутствие достаточных данных для такого вывода. Статус `completeness: "api_paginated_unverified"` **по-прежнему не гарантирует** полноту всех скрытых данных и веток. Агент должен различать архив доступной выбранной ветки и независимо подтверждённый полный серверный архив.
