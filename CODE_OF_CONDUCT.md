# Community guidelines / Правила сообщества

Be respectful and constructive. Assume good intent, criticize code rather than people, and make discussions useful to newcomers. No harassment, hate speech, threats, doxxing, or publication of other users' confidential ChatGPT content. Maintainers may moderate Issues and pull requests that violate these rules.

Обсуждайте код уважительно. Критика решений допустима; оскорбления, угрозы, травля, дискриминация и публикация чужих личных данных недопустимы. Сопровождающий может модерировать Issues и Pull Requests.

Report private security matters through the route in [SECURITY.md](SECURITY.md), not publicly.
