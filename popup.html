ChatGPT → Obsidian

Протокол пар «запрос → ответ», ссылки на сообщения и файлы, исходный JSON и LOG. Данные обрабатываются в браузере.

Исходящие файлы и изображения скачиваются по умолчанию. Входящие — только по отдельной галочке. Между файлами по умолчанию пауза 1,5 сек. При временных ошибках — до двух повторов. Во вкладке ChatGPT появится панель прогресса.
