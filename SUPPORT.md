# Support / Поддержка

**English:** For usage questions, defects, and feature proposals, open a [GitHub Issue](https://github.com/dmitromelnikoff/chatgpt-obsidian-exporter/issues). Include extension version, Chrome version, reproduction steps and a **synthetic/redacted** example. Don't post entire chats or confidential files. See [troubleshooting](docs/troubleshooting.md).

**Русский:** Вопросы, ошибки и предложения размещайте в [GitHub Issues](https://github.com/dmitromelnikoff/chatgpt-obsidian-exporter/issues). Укажите версию расширения, Chrome и шаги воспроизведения. Прилагайте только **искусственные или обезличенные** данные. Не публикуйте личные разговоры и файлы. См. [устранение проблем](docs/troubleshooting.ru.md).

GitHub Discussions are not assumed to be enabled. Security reports: see [SECURITY.md](SECURITY.md).
