# Приватность

Это клиентское Chrome-расширение Manifest V3; в коде этой версии нет SDK аналитики и отдельного сервера сбора данных. ZIP формируется в браузере и скачивается средствами Chrome.

Для выполнения задачи расширение обращается к API сессии и разговоров ChatGPT и к разрешённым адресам файлов. При этом используются данные авторизации действующей сессии, то есть **сетевые запросы выполняются**, но отдельной отправки вашего архива на сервер разработчика нет.

ZIP может содержать полную переписку, метаданные, DIL, идентификаторы, имена файлов и приватные документы. Храните его у себя. При экспорте через Popup входящие загрузки выключены по умолчанию, а кнопка «Экспорт ZIP» на странице намеренно включает доступные входящие вложения. Имена и метаданные могут оставаться в JSON и реестрах. Настройки задержки сохраняются в `localStorage` интерфейса расширения. Видимость кнопки «Экспорт ZIP» (по умолчанию включена) управляется первой галочкой Popup и сохраняется локально через `chrome.storage.local`. Для этого используется стандартное разрешение `storage`; содержимое чата в этой настройке не хранится.

Не прикладывайте реальные чаты, личные снимки экрана, токены и сетевые дампы к публичным Issues. Перед передачей кому-либо проверяйте не только Markdown, но и весь JSON.

Используются внутренние интерфейсы ChatGPT, которые могут меняться. См. [SECURITY.md](../SECURITY.md).
