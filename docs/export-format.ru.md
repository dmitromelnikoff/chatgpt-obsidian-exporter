# Формат архива

Каждый экспорт получает новую корневую папку с локальной временной меткой. Русские имена внутренних файлов — часть существующего формата совместимости с Obsidian.

- `00_Протокол.md` — нумерованные шаги запрос–ответ, ссылки на заголовки `## NNN. ...`.
- `01_Переписка/Часть-NNN.md` — читаемый Markdown, большие чаты разбиты на части.
- `02_Артефакты/` — реально скачанные файлы и созданные безопасные SVG; может отсутствовать при отсутствии файлов.
- `03_Исходники/conversation.json` — доступный сырой ответ API, без гарантии полного серверного архива.
- `03_Исходники/conversation.log` — текстовый LOG.
- `03_Исходники/steps.json`, `artifacts.json`, `manifest.json` — сведения о шагах, файлах и полноте.
- `03_Исходники/DIL/*.txt` — исходная разметка отдельных сложных сообщений.
- `04_Отчёт экспорта.md` — результаты скачивания, ошибки, пропуски и ограничения.

**Искусственный пример** без личных данных:

```markdown
[[Пример чата_2026-01-01_12-00-00/01_Переписка/Часть-001#001. Объясни алгоритм|001. Объясни алгоритм]]
**📤 [[Пример чата_2026-01-01_12-00-00/02_Артефакты/example.txt|example.txt]]**
```

Корневая папка является частью ссылок. Переносите её **целиком внутри одного vault**. Файлы, которых реально нет в ZIP, не должны получать ложные работающие ссылки.

Сложный Intelligent UI сохраняется как доступное статическое представление и исходный DIL. Интерактивное состояние и часть ссылок на источники могут быть недоступны.
