# Устранение неполадок

- **Экспорт не запускается:** откройте обычную страницу разговора `https://chatgpt.com/c/...`, проверьте активную вкладку, сообщение в окне расширения и консоль Chrome. Инъекция выполняется после нажатия.
- **Мало сообщений:** возможен сбой API и переход к резервному извлечению из страницы. Посмотрите оценку полноты в `04_Отчёт экспорта.md`. Некоторые ветки и скрытые записи недоступны.
- **Нет вложений:** смотрите `artifacts.json` и отчёт: входящие могут быть отключены, действуют лимиты, ссылки устаревают, сервер возвращает ошибки. Указатель не гарантирует скачиваемый файл.
- **Не работают Obsidian-ссылки:** распакуйте **всю папку экспорта** в один vault. Не переименовывайте части и не переносите вложения отдельно.
- **Intelligent UI выглядит иначе:** интерактивность не воспроизводится. Исходные данные некоторых компонентов лежат в `03_Исходники/DIL`.
- **Не скачивается ZIP:** проверьте разрешения загрузок Chrome, панель экспорта и консоль, затем повторите попытку. Есть ограничения ZIP32 и суммарного объёма вложений.

В отчёте об ошибке указывайте версии расширения и Chrome, шаги воспроизведения и только **обезличенные** фрагменты.
