# Участие в разработке

Спасибо за помощь. Предпочтительны небольшие понятные изменения. Новые большие зависимости или полная переработка архитектуры требуют отдельного обоснования.

1. Прочитайте [Разработку](docs/development.ru.md) и [Архитектуру](docs/architecture.ru.md).
2. Создайте Issue с воспроизводимой проблемой или предложением либо найдите существующий.
3. Создайте отдельную ветку, меняйте минимально необходимое и документируйте поведение.
4. Выполните `node tests/smoke.js`, `node --check` для затронутых JS и `python3 scripts/package_extension.py`.
5. Если менялись UI или работа с API, проверьте распакованное расширение в Chrome.
6. Откройте Pull Request с описанием, тестами и ограничениями.

**Приватность:** никогда не публикуйте настоящие разговоры, файлы, изображения, ключи, cookies и токены. Используйте вымышленные минимальные примеры.

**Лицензия ещё не выбрана.** Перед существенным вкладом согласуйте с сопровождающим лицензию и условия участия через Issue.

Подходящие первые задачи: улучшение сообщений об ошибках, синтетические тесты новых компонентов, документация на двух языках, проверки сложных путей ZIP.
